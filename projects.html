Multilingual Video Translation System

AI video localisation

An end-to-end pipeline that takes a video, transcribes its speech with Whisper, translates the transcript, synthesises new speech and lays it back over the original footage. A Streamlit interface handles upload and download.

Stack
Python, Whisper, FFmpeg, Streamlit, gTTS
Outcome
  • 14% word error rate and 0.65 BLEU; a one-minute video processes in about 45 seconds on a local CPU.
  • FFmpeg time-stretching keeps translated audio within 150 ms of the original timing.

Nazar

Code, by Groww 2026 submission

A market watchlist built around one question: what changed while I was away, and does it matter? A deterministic engine scores every watched stock from 0 to 100 on volume, volatility, breakouts, reversals and the move since your last visit. Gemini only turns those pre-computed facts into a one-line explanation.

Stack
React 19, TypeScript, Vite, Tailwind CSS, Express, Supabase (Postgres, Auth), Google Gemini
Outcome
  • Per-user price snapshots measure change since your last visit, not just since yesterday’s close.
  • Row-level security on every watchlist query, and deterministic fallback text when the LLM is unavailable.

MailFlow

ReachInbox engineering assignment

An email scheduler and dashboard. Emails are scheduled through an API, stored in PostgreSQL and sent as delayed BullMQ jobs with no cron, under Redis-backed hourly rate limits. Elasticsearch handles full-text search.

Stack
TypeScript, Express, PostgreSQL, Redis, BullMQ, Elasticsearch, React, Tailwind CSS
Outcome
  • A reconcile watchdog re-enqueues jobs stranded by worker or API crashes, without duplicate sends.
  • A Slack alert fires when a sender hits its hourly limit, at most once per hour.

Adaptive Diagnostic Engine

Adaptive testing backend

A GRE diagnostic that adapts as you answer. After each response it updates an ability estimate inspired by Item Response Theory and picks the next question to match. At the end, an LLM turns the session into a personalised study plan.

Stack
Python, FastAPI, MongoDB Atlas, Groq API (LLaMA 3.3 70B)
Outcome
  • REST APIs for test sessions, adaptive question selection and answer evaluation.
  • A three-step study plan aimed at each learner’s weak spots.

Self-Pruning Neural Network

Deep learning experiment

A network that removes its own weights while it trains. Each weight gets a learnable sigmoid gate, and an L1-style sparsity penalty pushes most gates towards zero. Trained and evaluated on CIFAR-10 at four sparsity strengths.

Stack
Python, PyTorch, torchvision, NumPy, Matplotlib
Outcome
  • At λ = 1.0, 78.6% of gates pruned with 61.78% test accuracy.
  • Accuracy held between 61.0% and 61.8% as sparsity rose from 46.7% to 78.6%.

Deadline OS

Chrome extension

A Chrome extension that reads your Gmail for deadlines (interviews, assignments, fee payments, applications) and keeps them in one place. A rule-based parser extracts dates and a confidence score decides what to save automatically.

Stack
JavaScript, Chrome Extensions (Manifest V3), Gmail API, Google Calendar API
Outcome
  • Understands formats such as “April 5”, “05/04/2026”, “in 3 days” and “next Friday”.
  • High-confidence deadlines sync to Google Calendar, with reminders 1 hour and 15 minutes ahead.
